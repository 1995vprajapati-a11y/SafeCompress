Privacy & help

SafeCompress is designed to process files locally.

What “local processing” means

Your chosen file is read by this page and processed in browser memory. This starter code does not send the file to a SafeCompress server.

Important limitations

Do not use this prototype for confidential documents until you have reviewed the source, tested network traffic and hosted trusted dependencies yourself. A website cannot guarantee privacy solely by using privacy wording.
